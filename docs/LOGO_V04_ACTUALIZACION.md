# Identidad visual v0.4 — logo corregido

- Se sustituyó el logo anterior, cuyos colores estaban debilitados por opacidad parcial, por **333.png** proporcionado por el usuario.
- Se mantuvieron el símbolo, el texto Lurín y el lema *Celebra tus raíces, vive Lurín*.
- La bienvenida ahora usa la imagen completa, sin filtros ni transparencia añadidos.
- La cabecera usa el símbolo cromático sin opacidad reducida.
- El icono adaptativo Android se renderizó de nuevo en sus cinco densidades, con fondo crema y motivo centrado.
- No se cambió el `applicationId` `pe.lurin.comunidad` ni se reutilizaron claves de otras aplicaciones.
- Las publicaciones, comentarios y chats multiusuario siguen requiriendo una **base de datos nueva** de Supabase. El código local no equivale a un backend desplegado.
- Si la marca es propiedad de otra organización, la publicación pública de sus recursos exige los permisos correspondientes.
